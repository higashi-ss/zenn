## はじめに

この記事では、Claude Codeをインストールした後に「ぜひやっておくべきこと」を3つ厳選して紹介します。

## 1. CLAUDE.mdを作成しよう

「このコードを修正して！」と、ざっくり依頼しながら完成形に近づけるやり方もあります。
しかし、曖昧な指示には曖昧な回答が返ってきます。結果としてやり取りが増え、トークンの無駄遣いになるため非効率です。

そのため、プロジェクトのルート階層に **`CLAUDE.md`** というファイルを事前に作成しておきましょう。

### なぜ必要か？

Claude Codeはセッション（会話のまとまり）ごとに記憶がリセットされる仕様です。しかし、起動時に自動で `CLAUDE.md` を読み込んでくれる機能があります。
ここにプロジェクトのコーディングルールや、よく使うコマンドなどを書いておくことで、最初から「このプロジェクトの前提条件」を理解してAIが動きます。
前提条件のズレを修正するために余分なトークンを消費せずに開発を進められます。

### 運用ベストプラクティス

* **ルールは短くシンプルに書く**
  公式ガイドでも短めに書くことが推奨されています。長すぎると、Claudeが重要な指示を見落としたり、無視したりし始めます。
* **役割ごとにファイルを分ける**
  ルールは `CLAUDE.md` に書き、現在の作業進捗やToDoは `TASKS.md` に、詳細な仕様書は `SPEC.md` に切り出しましょう。
  `CLAUDE.md` の中には「タスクの進捗は`TASKS.md`を、仕様は`SPEC.md`を参照すること」とだけ記載してリンクさせるのがベストです。

:::message

 `TASKS.md` や `SPEC.md` といったファイル名は、自分が分かりやすい名前（例： `TODO.md` や `仕様書.md`）に自由に変えても問題ありません。
ただし、`CLAUDE.md` だけはこの名前でなければいけません。
1文字でも間違えたり小文字にしたりすると、Claudeが設定を認識できなくなるため、ファイル名は十分に気をつけてください。

:::

### 導入方法とプロンプト

既存プロジェクトで使用する場合、Claude Codeのターミナル内で `/init` コマンドを実行することで`CLAUDE.md`を自動作成できます。
新規開発の場合でも、下記プロンプトのような指示出しをすれば自動作成が可能です。

```プロンプト: プロンプト
===
ここに作成したい成果物の草案を記載
===

この草案をもとにCLAUDE.md, SPEC.md, TASKS.mdを作ってください。
仕様はSPEC.mdにまとめ、タスクを分解して実装計画をTASKS.mdに記述してください。

使用技術・懸念点・トレードオフなど、さまざまな観点について私にAskUserQuestionを用いて詳細なヒアリングを行ってください。

質問は表面的・自明なものを避け、私自身も言及していない前提・ルール・判断基準が
浮かび上がるような質問にし、深掘ってください。

```

## 2. hooksを設定しよう

プロンプトでの指示はあくまで『お願い』であり、強制力がありません。
一方、hooksを使えば『Claudeがアクションを起こす前後』に特定の処理を強制的に実行させることができます。

### どう使う？

システム開発ではAIに編集してほしくない機密性の高いファイルがあります。
hooksを設定することで、特定のファイルへのアクセスを厳格に禁止したり、危険なコマンドの実行を未然にブロックできます。
hooksには使うタイミングによって以下のようなフックが存在します。

| フック名 | タイミング |
| ---- | ---- |
| `PreToolUse` | ツールを使う「前」 |
| `PostToolUse` | ツールを使った「後」 |
| `UserPromptSubmit` | 指示を送った瞬間 |
| `Stop` | 作業を終えた瞬間 |

おすすめの活用例として、上記のような『特定ファイルへの編集制限』や『編集後の自動コードフォーマットの徹底』などが挙げられます。
プロンプトの『お願い』をhooksによる『強制力』に変える事で、より安心して開発業務ができます。

※hooksの具体的な設定方法はOSごとに手順が異なりますので本記事では割愛します。
下記に公式の参照リンクを記載しておりますのでご確認ください。

@[card](https://code.claude.com/docs/ja/hooks-guide)

### Claude Codeのプラグイン機能とは？

Claude Codeには、外部ツールと連携し、AIの能力を拡張できるプラグイン機能が標準で備わっています。
コマンドを数行叩くだけで、デフォルトの状態から一気に「調べる力」や「考える力」をパワーアップさせることができます。今回は、特に入れておくべきおすすめプラグインを2つ紹介します。

### おすすめのプラグイン

* Superpowers
  * Claude Codeの「考える力」を底上げするプラグインです。単純にコードを書かせるだけでなく、プランニング、テスト駆動開発、体系的なデバッグ手法をAIに強制させることができます。「とりあえず書く」のではなく、賢く計画的に実装を進めてほしい時に重宝します。
  * 追加する時のコマンド
  
  ```bash
    /plugin marketplace add obra/superpowers-marketplace
    /plugin install superpowers@superpowers-marketplace
  ```

* Context7
  * Upstash Context7のMCPサーバーを利用したプラグインです。最新の公式ドキュメントを直接検索してコンテキストに注入してくれるため、AIが古いデータを参照したり、誤った情報を出力する現象（ハルシネーション）を防ぎます。
  * 追加する時のコマンド

  ```bash
    claude mcp add context7 -s project -- npx -y @upstash/context7-mcp
  ```
