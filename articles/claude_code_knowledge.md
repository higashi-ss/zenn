## はじめに

こんにちは！
この記事では、Claude Codeをインストールした後に「絶対にやっておくべきこと」を4つ厳選して紹介します。

Claude Codeは、インストールさえしてしまえばすぐに会話ベースで簡単にコーディングができて非常に優秀です。
しかし、実はただ適当に指示を出すだけだと、自分の求めているアウトプットが出るまでに時間がかかってしまうことがあります。

AIを最大限に活かし、開発を劇的にスピードアップさせるためのおすすめ設定やテクニックを分かりやすく解説します。

### 対象読者

* Claude Codeをすでにインストール済みの方
※「まだインストールしていない！」という方は、下記を参照し、導入後にこの記事を読んでみてください。

## 1. CLAUDE.mdの作成しよう

「このコードを修正して！」と、ざっくり依頼しながら完成形に近づけるやり方もありますが、トークンを余分に使用することになりClaude Codeではあまり効率がよくありません。

そこでおすすめなのが、プロジェクトのルート階層に **`CLAUDE.md`** というファイルを事前に作っておくことです。

### なぜ必要か？

Claude Codeはセッション（会話のまとまり）ごとに記憶がリセットされる仕様です。しかし、起動時に自動で `CLAUDE.md` を読み込んでくれる機能があります。
ここにプロジェクトのコーディングルールや、よく使うコマンドなどを書いておくことで、最初から「このプロジェクトの前提条件」を理解してAIが動きます。
前提条件のズレによる余分なトークン消費をせずに開発ができます。

### おすすめの運用ベストプラクティス

* **ルールは短くシンプルに書く（目安：60〜300行以内）**
  公式ガイドでも短めに書くことが推奨されています。長すぎると、Claudeが重要な指示を見落としたり、無視したりし始めます。
* **役割ごとにファイルを分ける**
  ルールは `CLAUDE.md` に書き、現在の作業進捗やToDoは `TASKS.md` に、詳細な仕様書は `SPEC.md` に切り出しましょう。
  `CLAUDE.md` の中には「タスクの進捗は`TASKS.md`を、仕様は`SPEC.md`を参照すること」とだけ記載してリンクさせるのがベストです。

### 導入方法とプロンプト

すでにあるPJで使用する場合、Claude Codeのターミナル内で `/init` コマンドを実行することで`CLAUDE.md`を自動作成できます。
新規開発の場合でも、下記プロンプトを参考に`CLAUDE.md`作成の指示出しをすることで自動作成は可能です。

```プロンプト
===
ここに作成したい成果物の草案を記載
===

この草案をもとにCLAUDE.md, SPEC.md, TASKS.mdを作ってください。
仕様はSPEC.mdにまとめ、タスクを分解して実装計画をTASKS.mdに記述してください。

使用技術・懸念点・トレードオフなど、さまざまな観点について私にAskQuestionToolsを用いて詳
細なヒアリングを行ってください。

質問は表面的・自明なものを避け、
私自身も言及していない前提・ルール・判断基準が
浮かび上がるような質問にし、深掘ってください

```

## 2. hookを設定しよう

### hookについて

* 理由（アクセス禁止ファイルを厳格に設定）
  * Claude Codeは非常に優秀ですが、時に不要なファイルを編集してしまったり、実行してほしくないコマンドを試そうとしたりすることがあります。Hookを設定することで、特定のファイル（`.env` や本番のクレデンシャルなど）へのアクセスを厳格に禁止したり、危険なコマンドの実行を未然にブロックできます。
* 解説
  * プロジェクトの`.claude/settings.json`にイベントフックを記述します。Claude Codeにはツール実行前（`PreToolUse`）やコマンド実行前（`Command`）など、複数のライフサイクルイベントが用意されています。
  * 例えば、「特定のファイルを編集しようとしたら、エラーを返して強制ブロックする」といったスクリプトや設定をHookに挟み込むことで、勝手にAIがコードを編集することを防ぐことができます。

## 3. 便利なプラグイン機能を活用しよう

:::message

こちらは個人の開発環境での推奨設定です。業務で利用する場合は、所属するプロジェクトのセキュリティ方針に沿って、許可が出てから導入を検討してください。

### Claude Codeのプラグイン機能とは？

Claude Codeには、AIの能力を外部ツールと連携してガッツリ拡張できるプラグイン機能が標準で備わっています。
コマンドを数行叩くだけで、デフォルトの状態から一気に「調べる力」や「考える力」をパワーアップさせることができます。今回は、特に入れておくべきおすすめプラグインを2つ紹介します。

### おすすめのプラグイン

* Superpowers
  * Claude Codeの「考える力」を底上げするプラグインです。単純にコードを書かせるだけでなく、プランニング、テスト駆動開発、体系的なデバッグ手法をAIに強制させることができます。「とりあえず書く」のではなく、賢く計画的に実装を進めてほしい時に重宝します。
  * 参考サイト（非公式）
  * @[card](https://blog.serverworks.co.jp/claude-code-superpowers)
* Context7
  * Upstash Context7のMCPサーバーを利用したプラグインです。AI最大の弱点である「古い情報（ハルシネーション）」を克服するため、最新の公式ドキュメントやバージョン固有のコード例をインターネット上のソースから直接検索してコンテキストに注入してくれます。
  * 参考サイト(非公式)
  * @[card](https://note.com/ai_driven/n/n5661e9e5353f)
  * @[card](https://github.com/upstash/context7/blob/master/i18n/README.ja.md)
